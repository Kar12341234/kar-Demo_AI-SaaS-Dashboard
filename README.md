# ClientFlow AI SaaS Dashboard Demo

Commercial-grade AI SaaS dashboard demo built for Fiverr, Upwork, Taobao, and freelance portfolio presentations.

## Project Overview

ClientFlow AI is a fictional AI GrowthOps platform for agencies, consultants, and B2B service businesses. The dashboard shows how an AI SaaS product can manage client workflows, AI usage, project delivery, automation playbooks, analytics, and admin settings from one polished interface.

## Features

- Executive dashboard with KPI cards:
  - Total Users
  - Revenue
  - AI Requests
  - Conversion Rate
- AI Usage and Token Usage monitoring
- Recent AI Tasks list
- AI Workflow Panel
- Project Status Table
- Activity Feed
- User profile and notification mockup
- Floating AI Assistant chat window
- Custom dark bubble dropdowns across the app
- Multilingual UI switcher: Traditional Chinese, Simplified Chinese, English
- Responsive dark SaaS interface
- Interactive demo actions for reports, workflows, projects, settings, and exports

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- React client-side state
- Lucide React icons
- Netlify-ready configuration

## Portfolio Purpose

This project is designed to demonstrate full-stack product thinking and frontend implementation quality for freelance clients who need:

## GitHub / Netlify-Ready

The project includes `netlify.toml` and `@netlify/plugin-nextjs`, so it is ready to connect to Netlify when deployment credits are available.

Recommended Netlify settings:

- Build command: `npm run build`
- Publish directory: `.next`
- Production branch: `main`

This repository can also be pushed to GitHub as a portfolio project without triggering a Netlify production deploy if changes are pushed to a non-production branch.
