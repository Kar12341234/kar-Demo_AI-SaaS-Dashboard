# AI SaaS Dashboard Demo

A polished Next.js dashboard demo for Fiverr and Upwork portfolio presentations. It presents a realistic AI SaaS product backend with analytics, AI workflow status, project management, and responsive dark UI.

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Responsive dashboard layout
- Netlify-ready configuration

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deploying to Netlify

This project includes `netlify.toml` and `@netlify/plugin-nextjs`.

- Build command: `npm run build`
- Publish directory: `.next`
